# Telegram UserBot

Многофункциональный юзербот на Telethon с RP-командами, загрузкой медиа (YouTube / Instagram / TikTok) и стелс-функциями.

## Запуск

```bash
pip install -r requirements.txt
python main.py
```

### Переменные окружения

| Переменная | Описание |
|-----------|----------|
| `API_ID` | API ID из my.telegram.org (обязательно) |
| `API_HASH` | API Hash оттуда же (обязательно) |
| `OWNER_ID` | Telegram ID владельца (обязательно) |
| `STRING_SESSION` | Строка сессии Telethon (опционально) |
| `PORT` | Порт Flask-статуса (по умолч. 8080) |
| `MEDIA_DIR` | Директория для скачанных файлов (по умолч. ./media) |

### RP-команды

Работают **только в личных сообщениях**. Для отправки RP-действия:

- **Любой пользователь** в ЛС — пишет команду, бот отвечает
- **Owner/Sudo** — реплай на чьё-то сообщение с командой (RP от имени бота к этому человеку)

Более 90 RP-действий. Список: `!rphelp`

## Зависимости

- `telethon` — работа с Telegram API
- `yt-dlp` — загрузка YouTube / TikTok / Instagram (видео, аудио, карточки)
- `curl_cffi` — обязателен для TikTok/Instagram (имперсонация браузера в yt-dlp)
- `requests` / `aiohttp` — HTTP-запросы
- `flask` — веб-статус
- `google-generativeai` — AI-помощник (Gemini, первичный провайдер)
- `edge-tts` — голосовые сообщения (`!tts`)

## AI-помощник

Работает через **Gemini** (основной провайдер) с автоматическим фоллбэком на **OpenRouter** (бесплатная модель `deepseek/deepseek-chat:free`). Все команды доступны владельцу и sudo-пользователям.

### Установка

В `.env` добавьте:

```env
GEMINI_API_KEY=...            # ключ Google AI Studio (ai.google.dev)
OPENROUTER_API_KEY=...        # ключ openrouter.ai (фоллбэк)
GEMINI_MODEL=gemini-1.5-flash        # модель Gemini
OPENROUTER_MODEL=deepseek/deepseek-chat:free
AI_TEMPERATURE=0.9            # креативность 0–1
AI_TTS_VOICE=ru-RU-SvetlanaNeural   # голос для !tts (edge-tts)
AI_MAX_HISTORY=200            # лимит сообщений из базы
```

Затем: `pip install google-generativeai edge-tts`

### Контекст и анализ

- `!summary @ник [n]` — выжимка переписки (3 предложения)
- `!vibe @ник` — настроение собеседника (агрессия/симпатия/вовлечённость)
- `!liar @ник` — поиск противоречий в словах
- `!sync @ник [n]` — сохранить историю до N сообщений в базу (до 500)
- `!fact @ник [факт]` — запомнить факт о человеке · `!facts @ник` — список · `!fact clear @ник` — очистить

> Переписка сохраняется в базу автоматически (только ЛС). Для старых сообщений используйте `!sync`.

### Редактура и проверка

- `!rewrite [стиль]` — переписать сообщение (вежливо/официально/токсично/гопник/свой)
- `!fix [текст]` — грамматика + автопереключение раскладки ENG↔RU
- `!factcheck` — проверка фактов и нестыковок
- `!args` — 3 контраргумента для спора
- `!tr [язык]` — перевод в Избранное
- `!ocr` — распознать текст с картинки (ответить на неё, затем команда)

### Медиа

- `!tts [текст]` — голосовое сообщение (тема — текст или ответ)
- `!circle` — гифка/видео → видео-кружочек (ответить на медиа, затем команда)

### Автоответчик

- `!auto @ник on [роль]` — автоответчик в ЛС с этим человеком. Роли: `девушка`, `враг`, `друг`, `босс`, свой текст = кастомный промпт
- `!auto @ник off` — выключить
- `!prompt @ник on` — вместо ответа присылать в Избранное 3 варианта ответа
- `!delay [сек]` — пауза перед ответом ИИ
- `!blacklist @ник` / `!whitelist @ник` — управление доступом автоответчика

### Эмодзи-триггеры

Поставьте реакцию на входящее сообщение в ЛС — разбор улетит в **Избранное**, чтобы не палить юзербота:
- 🤔 — скрытый смысл, подтекст и манипуляции
- 🤬 — токсичность, пассивная агрессия и «красные флаги»
- ⚡ — краткая выжимка (TL;DR)
- 🤓 — перевод на русский/английский
- 🤡 — жёсткий саркастичный роаст

Справка: `!helpai реакции`

### Квест

- `!quest начать` — запустить текстовый RPG-квест
- `!quest [действие]` — сделать ход

Справка по разделам: `!helpai` → `!helpai контекст`, `редактура`, `проверка`, `медиа`, `автоответчик`, `квест`, `all`.
